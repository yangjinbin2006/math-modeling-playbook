## 0. 两条铁律（先读，破坏 = 比赛事故）

1. **防泄露铁律：绝不让整篇论文一次性进入任何在线工具/检测器/改写网站。**
   - 泄露风险：内容进第三方库、被收录/被逐字复用，比赛"未交先泄"= 事故；
   - 指纹风险：整篇统一变换 = 句长节奏均匀、连接词密度一致、段落形状雷同 =
     "一键改写指纹"——检测器与评委**都能**看出"全文一键改过"，反而更糟；
   - 一致性风险：整篇改完才发现前后矛盾/模型名漂移，返工量爆炸、数值易被误改。
   - ⇒ 操作规则：**一次只改一节/一个论证段，全程本地处理**（正文见 §3）。
2. **合规铁律：AI 声明不变；不用规避型工具隐瞒未声明使用；查重红线靠原创与规范引用，不靠改写工具。**
   - 检测器（如 LLM-Detector / C-ReD 等开源模型）只当"自测-改写-复测"闭环里的仪表，
     一次只喂一节；**它的用途是质量仪表，不是攻击目标**。

## 2. 为什么"不能整篇同时降"（你的提醒 = 本指南的制度源头）

| 风险 | 机理 | 后果 |
|---|---|---|
| L1 内容泄露 | 整篇上传第三方平台 | 未交先泄、被收录/逐字复用 → 事故 |
| L2 一键改写指纹 | 全篇统一变换：句长节奏、连接词、段落形状均匀化 | 检测器与评委双重可辨，且文风断裂 |
| L3 一致性灾难 | 改完才发现前后矛盾、模型名漂移、数值被误改 | 返工量爆炸，触发语言总结 5.3/5.4 红线 |

⇒ 规则：**切节 → 逐节改写 → 每节校验 → 局部微调**（§3 / §4），禁止任何"全文一次性处理"的操作。

## 3. 增量改写 SOP（逐节、本地执行）

**Step 1 切节**：按 摘要 / 问题重述 / 问题分析 / 模型建立 / 模型求解 / 分析与检验 / 评价与改进 切成节，
一次只取一节到编辑器。（摘要最后写、最后改——先有正文证据链。）

**Step 2 标机味**（读整节一遍，标出所有"AI 痕迹"，最强优先）：
- not-X-but-Y 式对照句、单句收尾重复论点；
- 刻意三联排比（三个"不仅…而且"）、满屏破折号；
- 膨胀化表述（平常事实说成"至关重要/具有重大意义"）；
- 模板口头禅：综上所述 / 不可否认 / 值得注意的是 / 由此可见；
- 加粗标签化（段首"定义：""方法："式押题）、翻译腔长句。

**Step 3 理解后重写**（不是逐词替换！）：
- 保留全部支撑事实：数值、公式、引用、结论**一个都不能丢**；不添加原文没有的事实；
  缺细节就写更简单的句子，或问队员补——**禁止编造**（来源：humanizer 方法论）；
- 拆长句、句长刻意交错（真人写作出句长短起伏）；
- 结论前置 + 数据倒推 + 反直觉案例先导，打散总-分-总；
- 特指数据代替空泛形容词（"误差 3.2%" 替 "效果较好"；"提升 12 倍" 替 "显著提高"）；
- 三连排比拆开、各自带证据；删口头禅，换"从数据来看/这说明了"；
- 全节按"一个自然段落 = 一个主观点"重排段落结构，不一句句打补丁。

**Step 4 自查（每节改完必做，读出声）**：
- 5 大残留信号：not-X-but-Y、单句收尾、破折号、三联排比、加粗标签；
- 一致性：模型名/符号/单位与摘要**一字不差**；关键数值锚定 `结果_锁定.json`；
- 句长是否有起伏；本章节是否满足论证三段式与"结果-为什么-意味着"收官。

**Step 5 交给 AI 的固定角色**（喂-吐之道）：AI 只做 ①初稿脚手架 ②逐节润色/查错 ③体检打分；
**关键内容由人定稿**。可选：本地开源检测器对"改后一节"打一次分作仪表参考（一次一节，不上传）。

## 4. 机味体检清单（交卷前，30 秒/节）

- [ ] 模板词密度：综上所述/不可否认/值得注意的是/首先其次最后 出现频率正常？
- [ ] 句长方差：连续 3 句同长 = 嫌疑；是否存在长短交错？
- [ ] 排比三联 / not-X-but-Y / 破折号刷屏清零？
- [ ] 加粗标签化：段首"定义/方法/结论："式红字清零？
- [ ] 数据密度：每段至少 1 个真实数值或对照（方法名/百分比/倍数）？
- [ ] 名词一致性：摘要↔正文↔图注↔结论 模型名一字不差？
- [ ] 图注表题"讲故事"（结论 + 数据如何支撑），不是罗列数字？
- [ ] 每问有"结果 → 为什么 → 意味着什么"收官句？
- [ ] 无"大段照抄原题 / AI 整段 / 往年论文"（查重红线 ≥25% 不送全国）？
- [ ] 本次 AI 辅助是否已记入 AI_使用记录.md、声明文件在支撑材料里？

## 5. 合规红线总表（比赛日贴第一屏）

1. AI 使用记录 + `AI工具使用详情.pdf` **照填**（框架为"声明式使用"，不是隐瞒）。
2. **不上传整篇**到任何在线工具/检测器/改写站；全部本地、逐节处理（铁律 1）。
3. **不使用**隐蔽规避型工具（"avoids AI detector!"类）隐瞒未声明 AI 使用（铁律 2）。
4. **不把查重当"改写游戏"**：相似度红线靠原文撰写 + 规范引用达成，不靠降重工具。
5. 检测器只作质量仪表（自测-改写-复测），一次一节。
6. 任何"改写"不得改动数值、公式、变量、引用与文档结构（最小化改写原则）。
