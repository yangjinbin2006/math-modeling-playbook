## ① 灵敏度分析（最小成本，必做）

**触发条件**：任何有假设参数/经验常数的题（B 题：n、角度、频段；预测类：权重、阈值）。

**标准流程**：
1. 列出关键参数（假设里的常数、阈值、权重、初值）。
2. 每个参数 ±5%、±10% 各重算一次（1 个参数 = 4 次运行，脚本化 10 分钟）。
3. 画**龙卷风图**（参数 × 结果偏移%，排序）或参数-结果折线图。
4. 写一句结论：结果对哪个参数最敏感 → 该参数必须进"不确定度表述"。

**通过标准**：±10% 扰动下结果波动 < 答案容差区间（B 题实证：n ±5% → d ±5%，属正常量级）。

**论文句式**："d 对折射率 n 最敏感（±5% n → ±5% d），故将 n∈[2.55,2.65] 纳入不确定度，报 d=7.68±0.15 μm。"
**证据级别**：龙卷风图 > 折线图 > 只写文本（本机 B 题正是栽在"只写文本"，见 ◐）。

## ② 稳健性（鲁棒性）检验

**触发条件**：数据有噪声/离群点嫌疑、结果依赖数据子集、预测/分类/拟合类题。

**标准流程**（三选二即可；时间紧只做"删 10%"）：
1. 删 10% 数据（随机删，重复 3 次看分布）→ 结果变化%。
2. 加噪声（高斯 σ = 数据标准差的 1–5%）→ 结果变化%。
3. K 折/留一交叉验证（预测类必做，报 CV 均值 ± std）。

**通过标准**：<10% 波动 = 稳健；**超过 10% 不隐瞒**——写进"误差来源/局限"，或当场换模型。

**B 题实证教训（最重要的一条）**：滑窗 FFT 发现 Si 有效频段频率漂移 11%（SNR 835–11167）→
常数 n 假设不成立，中期被迫改色散模型（Si RMSE 从 2.0 修正回 1e-3 量级）。
**这就是稳健性检验的真实价值：提前暴露模型缺陷，而不是交稿前才发现。**

**论文句式**："随机删减 10% 波数点后 d 偏移 0.8%，加高斯噪声 σ=0.5% 后偏移 1.2%，表明结果对数据扰动稳健。"

## ③ 误差分析

**触发条件**：一切有拟合/回归/预测结果的题（必做）。

**标准流程**：
1. 算 RMSE、MAPE、R²（numpy/scipy 一行代码）。
2. 画残差图（残差 vs 自变量或拟合值）；残差**零均值、无趋势** = 好。
3. 写"误差来源"三段：模型误差（假设简化）、数据误差（仪器/噪声）、方法误差（离散化/数值）。

**通过标准**：拟合类 R² ≥ 0.94 常见阈值；残差零均值无结构。**有结构残差 = 模型错**，不是"误差大就完了"
——B 题中期 Si RMSE=2.0 的根因就是常数 n 忽略色散，残差图当场定位。

**论文句式**："双光束拟合残差零均值、σ 不随波数增长（fig），RMSE 1.1×10⁻³，优于表 X 文献水平。"

## ④ 对比验证

**触发条件**：必做。三类基准至少打一个：
1. **真实/官方数据**：题给附件、参考答案区间（A 题 1.391643s / B 题 SiC≈7.5–7.6μm 即官方锚点）。
2. **文献值**：论文/标准表（我们的 B157、B060 就是）。
3. **简单基准模型**：平均值/线性/人为给定 = 你模型的"对照组"（B 题：双光束 vs 多光束 Airy）。

**做法**：同图/同表对比 + **差异解释段**。差异解释写得越物理/统计，可信度越高。

**论文句式（B 题实测）**："本解 SiC 7.68 μm 介于 B157(7.604) 与 B060(7.455) 之间（偏差 1.0%/3.0%），
差异源于二者分别采用 Cauchy 色散与 Drude 声子修正，本机采用……"——**差异 = 模型选择之差，不是错误。**

| ① 灵敏度 | 20–40 分钟（含龙卷风图） | 1 个关键参数 ±10% + 一句结论 |

## 实战验证回写（2026-09-10 · 国一版完整复跑闭环后）

B 题国一版复跑按本清单（循环版）执行，四条修正如下，全部有实证：

1. **灵敏度结果必须并入不确定度**（清单新增强制句）：
   本次 n_lit ±10% → d ∓9–11%（解析关系 d=P/n），θ±0.5° <0.03%、频段±150 ≤1.4%；
   σ_d 由 n 文献误差主导（1.2–1.9%）。→ 写法："d=7.77 μm，其中 1.9% 不确定度来自折射率文献值（识别锚）"。
2. **通过标准要有决策树，不是报数字**：
   本次 Si 10° 频段外扩 +150 cm⁻¹ 时 d 偏移 −18%（条纹数不足）→ 处理 = 限制频段 + 写进局限，而非隐瞒。
   规则：<10% 报"稳健"；≥10% 先归因（数据子集/边界/模型），再选择"限制条件/换模型/如实报告"。
3. **检验间循环**（清单已写循环设计，本次实证）：
   灵敏度敏感参数（n_lit）→ 直接进了不确定度合成；稳健性删数据/加噪 → 与合成回归 SNR 曲线互相印证；
   误差残差含条纹频率结构（DW≈0）→ 不是失败，触发统计检验 → 归因"恒定包络双光束对幅度刻画不足"→
   并入问题3 多光束判据第 (iii) 条成为证据。**残差有结构：先归因（模型/数据/方法三段），再决定升级或如实报告。**
4. **时间盒修正**：统计证据（直方图/Q-Q/DW/频谱/热图/合成回归）实测 60–90 分钟，不是"现成函数 30 分钟"；
   Step2 总预算按 3–4h 排（见时间盒表）。

**清单盲区补记**：四类检验覆盖"结果稳定性"，未覆盖"方法正确性证明"（合成数据回归）与"参数可辨识性"
