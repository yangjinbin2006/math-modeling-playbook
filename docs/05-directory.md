# 参赛文件夹目录结构模板（一次参赛 = 一个文件夹）

> 作用：把**原始题目、每道题的建模笔记、代码、结果、论文**分文件夹整理好，
> 让 AI Agent 能在文件夹里完成建模→求解→论文全部工作，也让"结果锁定、
> AI 留痕、可复现"这三条红线有固定的落点。
> 版本依据：参考 [cumcm-paper-hand-skill](https://github.com/Mr-Potato-123/cumcm-paper-hand-skill)
> 的目录结构模板，按竞赛红线（题目只读、结果锁定、AI 使用记录）增补。
> 用法：把 `my-mcm-project` 改成你的项目名，复制下面的结构。

```
my-mcm-project/
├── README.md                        # 项目说明：题目清单、小组成员、进度（领队维护）
├── 题目/                            # ★ 原始题目与数据（只读！不得修改）
│   ├── 2026A_题目.pdf               # 原始题目原文
│   └── 附件/
│       ├── data1.xlsx
│       └── ...
├── 问题A/                           # ★ 每个题目一个文件夹
│   ├── 建模笔记.md                  # 本题建模全过程记录（论文第一手素材）
│   │                                #   → 模板：templates/modeling-notes.md
│   ├── 代码/
│   │   ├── main.py                  # 本题求解代码（可原样跑出论文结果）
│   │   └── README.md                # 代码说明：依赖、运行方式、软件版本
│   ├── 结果/
│   │   ├── 图1_数据分布.png
│   │   ├── 图2_模型对比.png
│   │   └── 结果_锁定.json            # ★ 结果锁定文件（results lock，论文锚点）
│   └── 解答.md                      # 本题完整解答草稿（论文章节素材）
├── 问题B/
│   ├── 建模笔记.md
│   ├── 代码/
│   ├── 结果/
│   └── 解答.md
├── 问题C/
│   └── ...
├── 论文/                            # 最终论文
│   ├── 论文.tex                     # ★ 唯一交付文档（模板：templates/paper.tex）
│   ├── 论文.pdf                     # XeLaTeX 编译产物（提交版）
│   ├── 附图/                        # 论文用图（高清/矢量）
│   └── (论文md草稿/)                 # 可选：先出 md 草稿供队伍确认，再落 tex
├── 支撑材料/                        # 国赛提交支撑材料
│   ├── AI_使用记录.md →            # ★ AI 使用记录（工具/版本/环节/提示词/采纳）
│   │                                #   → 模板：templates/ai-usage-log.md
│   └── AI_工具使用详情.pdf          # ★ 提交版（无队伍信息与模型名）
└── 参考资料/
    ├── 文献1.pdf                    # 自己找的参考文献（逐篇核实存在）
    └── 获奖论文.pdf
```

## 使用说明

| 文件夹 | 作用 | 谁维护 | 红线要点 |
|--------|------|--------|---------|
| `题目/` | 题目原文与附件，**只读** | 队长（第一天放好） | 不修改；数据有问题先证明源头再改 |
| `问题X/建模笔记.md` | 建模全过程记录，论文第一手素材 | 建模手（AI 协助） | 每问闭环：分析→建模→求解→结果→小结 |
| `问题X/代码/` | 可运行的求解代码 | 编程手（AI 协助） | **能原样跑出论文结果**；软件名+版本写正文 |
| `问题X/结果/` | 图表与数据；`结果_锁定.json` 为论文锚点 | 编程手 | 关键数值全部进结果锁定，多方核对一致 |
| `问题X/解答.md` | 本题完整解答 | 建模手 | 每问结尾有"结果→为什么→意义" |
| `论文/` | 论文 md 草稿 → tex 终稿 → PDF | 论文手（AI 协助） | 摘要最后写；图≥15张自己画 |
| `支撑材料/` | AI 记录 + 提交用 PDF | 全队 | 记录从第一天写起，不事后补 |
| `参考资料/` | 文献与范文 | 全队 | AI 给的文献必须到库核实 |

## 两条补充规则

1. **建模手要给队友留接口**（输入是什么/输出是什么/参数怎么获得/公式在哪步用/结果如何检验）——
   写进 `建模笔记.md` 的每问小结里；这是"三人融合、不各管一摊"的文件级保证。
2. **每问结果锁定后强制换新会话**——从 `建模笔记.md` + `结果_锁定.json` 冷启动下一问，
   不把上一问的上下文带下去（防上下文腐烂）。

## 不整理也能做的说明

如果队伍没按此结构整理，AI Agent 会先询问/扫描现有文件，按上面的逻辑重新归拢
（只建链接和整理后的笔记，不移动原始文件），效果略打折但可工作。
