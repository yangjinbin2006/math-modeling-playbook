# 建模笔记模板（每题一份，论文的第一手素材）

> 每个题目的 `建模笔记.md` 用本模板。建模时随手记，**越详细，论文质量越高**。
> 它是 AI 写论文的**唯一素材来源**——论文里每个数值都必须能追溯到笔记或结果文件。
> 参考 [cumcm-paper-hand-skill](https://github.com/Mr-Potato-123/cumcm-paper-hand-skill)
> 的建模笔记模板，按"留接口给队友、防数据泄漏、结果锁定"增补。
> 每个子问题按闭环记录：**问题分析 → 模型建立 → 模型求解 → 结果分析 → 小结**。

# 问题X · 建模笔记（题目：____）

## 0. 题目与口径声明（数据题必填，防止口径错 85%）
- **题目要求**：一句话说清本题要我【决定/预测/评价】什么。
- **数据来源**：【题目附件 / 自找（哪里找的）】。
- **口径声明**：距离语义、比值/覆盖率分母、单位换算、公式近似级——**每条逐字写清**。
- **独有元素**：本题题面/数据里"只属于这道题"的专有名词、特殊约束、数据特征值（反同质化自查用）。

## 1. 问题分析
- **题目要求**：【该问要做什么，一句话】
- **关键难点**：【难在哪里：数据缺失？维度高？非线性？约束复杂？】
- **数据/变量特征**：【手头有什么数据，变量关系有何趋势（可贴图）；先做"体检"三查：
  表结构 / 几何拓扑（锚点-偏差-退化）/ 口径；防数据泄漏（同一对象重复观测≠独立样本，按个体分层）】
- **总体思路**：【打算用什么模型，为什么适合（关键：写"为什么"，不写"用什么"）】
- **求解与检验方法**：【用什么算法，用什么指标检验（回归/分类指标按场景选、讲理由）】

## 2. 模型建立
- **变量定义**：【符号表：符号 | 含义 | 单位——全文统一，学科惯例优先】
- **模型原理**：【模型核心思想、背景、适用条件与失效条件、出处（哪篇文献）】
- **公式**：【公式 + 每一项含义；优化问题给标准型：目标函数/决策变量/约束】
- **参数确认**：【参数取值与理由（以物理理由与敏感性为准，不调参对齐论文数字）】

## 3. 模型求解
- **算法**：【算法名 + 关键参数（种群大小、迭代次数、学习率等）+ 终止条件 +
  为什么选它（常规方法为何不适用，如何改造）】
- **代码位置**：【`代码/` 下哪个文件，运行方式，软件版本】
- **求解结果**：【核心数值结果 —— 存进 `结果/结果_锁定.json`（论文锚点）】

## 4. 结果分析
- **结果呈现**：【关键图表 + 每张图表说明了什么（看图说话，每图必配分析）】
- **检验证据**（至少要做几项，写入论文检验节）：
  - [ ] 常识检查（量纲/物理边界：温度非负、比例∈[0,100]）
  - [ ] 数值验证（步长收敛 / 训练-测试误差 / baseline 对比）
  - [ ] 敏感性/稳健性（±1%、±5% 扰动 / 多 seed / 加噪）
  - [ ] 双路线/独立求解互验（两路误差小）【单兵/双人必做】
  - [ ] 四件套（退化 / 独立数值 / 自洽对称 / 边界自洽）
  - [ ] 落参考答案或给差异解释（不调参命中）
- **合理性**：【结果是否符合实际背景，是否符合假设；异常结论给 [DIFF]/原因，不掩盖】

## 5. 小结（给队友/下一问留接口）
- 【本问建立了…模型，求得…，指标为…，结果将作为…用于下一问。】
- 【给队友的接口：输入是什么 / 输出是什么 / 参数怎么获得 / 公式在哪步用 / 结果如何检验】

---

## 答题节奏提醒（写笔记时对照）
- 每个处理的**一行理由**：数据缺失/异常怎么处理、为什么这么选（写完可核对、可复现）。
- 想"直接套模型"时先停一下：**先拆问题结构（变量/约束/目标）再选模型**。
- 模型 3–4 小时跑不出来就换方案，别在沉没成本上耗。
